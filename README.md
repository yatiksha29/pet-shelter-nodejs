# Pet Shelter Management System

A full-stack CRUD web application built to help manage pet shelter
records — tracking pets available for adoption and the adopters
interested in them.

## Why I Built This

Pet owners often struggle to find a secure, trustworthy shelter for
their pets when they're temporarily unable to care for them — whether
due to travel, an emergency, or another life situation where taking
the pet along just isn't possible. A reliable shelter management
system makes it easier for shelters to organize and manage pets in
their care, giving owners a safe and dependable option during those
times, and helping shelters run more efficiently.

## Features

- **Pet & adopter record management** — add, view, update, and delete
  pet and adopter details.
- **Structured database** for storing and retrieving pet and user
  data, with validation applied across all CRUD operations.
- **Responsive UI** built with HTML, CSS, and Bootstrap, so shelter
  staff can manage listings from any device.

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | HTML, CSS, Bootstrap |
| Backend | Node.js, Express.js |
| Database | MySQL |

## Getting Started (Local Setup)

```bash
git clone https://github.com/yatiksha29/pet-shelter-nodejs.git
cd pet-shelter-nodejs
npm install
node yats-server/server.js
```

Set up your MySQL database and connection details before running
locally.

## What This Project Demonstrates

- Designing a relational database schema from scratch
- Implementing full CRUD operations with data validation
- Building a responsive frontend UI with Bootstrap
- Structuring an Express.js backend with clean route handling
